# 随身写字板（Clipboard Anywhere）

[English](README.md)

Clipboard Anywhere 是一个适用于 Minecraft Forge 1.7.10 的模组，为 BiblioCraft 写字板添加可移动悬浮窗。玩家无需返回实体写字板旁，即可查看页面、切换任务状态并管理多个已绑定写字板。

## 功能

- 通过可移动的游戏内悬浮窗使用 BiblioCraft 写字板。
- 每名玩家可以绑定和管理多个写字板。
- 可在悬浮窗中查看页面、翻页和切换任务状态。
- 可读取玩家背包中或已加载放置位置的写字板，并支持跨维度使用。
- 写字板暂时不可用时，仍可查看最后一次同步的页面。
- 支持移动、缩放、自定义和折叠悬浮窗。
- 可在 HUD 和受支持的 GUI 界面中使用。
- 支持自行配置快捷键，并兼容 ModernKeyBinding 提供的组合键。
- 内置英文和简体中文本地化。

## 运行要求

- Minecraft 1.7.10
- Minecraft Forge 10.13.4.1614
- BiblioCraft 1.11.7
- 兼容 Minecraft 1.7.10 的 Mixin 引导环境，例如 UniMixins

客户端和服务端都必须安装 Clipboard Anywhere。


## 使用方法

### 绑定写字板

手持 BiblioCraft 写字板，潜行并右击空气。模组会为该写字板分配持久标识，并将其设为当前绑定。如果写字板已经绑定，重复该操作会选中已有绑定，而不会重复创建。

悬浮窗可以从以下位置找到写字板：

- 当前绑定玩家主背包中的任意槽位；
- 写字板最后一次放置的位置，但目标维度和区块必须已经由服务端加载。

Clipboard Anywhere **不会**主动加载维度或区块。位于容器、其他玩家背包或掉落实体中的写字板会被视为失联。

### 操作悬浮窗

- 鼠标移入展开的悬浮窗后，标题行会原位替换为操作控件；移出后恢复标题，悬浮窗高度和位置不会改变。
- 点击绑定名称可打开写字板列表。
- 点击铅笔图标可修改当前绑定名称。
- 点击 × 图标可解绑。解绑不会删除实体写字板或其中的任务。
- 拖动操作行中的空白区域可移动悬浮窗。
- 点击齿轮图标进入布局编辑。布局编辑支持拖动、等比缩放、分别调整背景和文字透明度，以及确认或取消修改。
- 点击折叠图标可将悬浮窗缩小为固定 8 × 8 图标。单击图标展开，拖动图标可改变位置。
- 点击任务复选框可循环切换 BiblioCraft 任务状态。
- 使用底部左右箭头翻页。

没有打开其他 GUI 时，需要先为 **切换写字板交互模式** 设置快捷键，再通过该快捷键打开不会暂停游戏的交互界面。已经打开受支持的 GUI 时，可以直接使用鼠标操作悬浮窗。

### 写字板失联

绑定失联后，悬浮窗会以只读方式显示最后一次同步的页面。如果存在其他可读取绑定，通常会自动切换到第一个可读取写字板。仍可手动选择失联绑定查看缓存或将其解绑；实体写字板再次可读取后会自动重连。

## 快捷键

为避免与大型整合包中的其他模组冲突，所有快捷键均**默认不绑定**。

| 操作 | 默认值 |
| --- | --- |
| 写字板上一页 | `NONE` |
| 写字板下一页 | `NONE` |
| 折叠/展开写字板悬浮窗 | `NONE` |
| 切换写字板交互模式 | `NONE` |

请在 **选项 → 控制 → 随身写字板** 中自行设置。未绑定时，Tooltip 会显示 `NONE`。如果 ModernKeyBinding 提供了带修饰键的组合键，Tooltip 会显示完整组合，而不是只显示基础按键。

受支持的文本输入框获得焦点后，悬浮窗快捷键会暂停响应，因此普通输入以及复制、粘贴、剪切、全选等组合键可以正常使用。

## 配置与存档数据

客户端布局设置保存在 `config/clipboardanywhere.cfg`。推荐使用游戏内布局编辑器进行调整。

| 设置 | 范围或行为 |
| --- | --- |
| 缩放 | `0.5` 至 `2.0` |
| 背景透明度 | `0.10` 至 `1.0` |
| 文字透明度 | `0.10` 至 `1.0` |
| 位置 | 相对最近的水平和垂直屏幕边缘保存 |
| 折叠状态 | 在不同游戏会话之间保留 |

写字板标识、每名玩家的绑定、显示名称、当前选择和缓存页面保存在服务端世界数据中。

## 兼容性说明

- 悬浮窗使用低优先级、可选的 GUI 输入 Hook，使自定义 GUI 库可以保留自身的输入处理逻辑。
- 安装 ModularUI2 时，Clipboard Anywhere 使用其可取消的输入前置事件，避免与其 GUI 重定向发生冲突。
- Minecraft 设置界面，以及已知的 Angelica、Sodium/Reese、NotFine 和 Iris 配置界面会隐藏悬浮窗，避免遮挡这些界面的控件。
- 实体 BiblioCraft 写字板始终是权威数据来源。Clipboard Anywhere 不会替代 BiblioCraft 的文字编辑器，也不能从悬浮窗修改任务文本。

## 构建

在 Windows 环境中，从仓库根目录执行：

```powershell
.\gradlew.bat spotlessApply
.\gradlew.bat check
.\gradlew.bat jar
```

Linux 或 macOS 环境请使用 `./gradlew` 代替 `.\gradlew.bat`。

重混淆后的模组 jar 会生成到 `build/libs`。

常用开发任务：

```powershell
.\gradlew.bat runClient
.\gradlew.bat runServer
```

运行专用服务端前，需要在生成的服务端运行目录中接受 Mojang EULA。当前仓库已不包含自动化测试源码集；`check` 目前用于验证格式、编译和已配置的静态检查。
